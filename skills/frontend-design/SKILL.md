# Frontend Design Skill

## Design Principles
1. **Rich Aesthetics**: WOW the user with vibrant HSL color palettes, dark modes, dynamic gradients, and smooth glassmorphism.
2. **Modern Typography**: Use clean font stacks (e.g. Inter, Outfit, Roboto) with distinct visual hierarchies.
3. **Micro-Animations**: Add subtle CSS hover effects, active states, and fluid transitions to keep the interface feeling responsive and alive.
4. **No Placeholders**: Use real or generated assets; never leave unstyled placeholder images or broken layout boxes.
5. **Aesthetic Standards**: Avoid basic default browser aesthetics or generic colors.
