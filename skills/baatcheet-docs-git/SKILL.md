# BaatCheet Docs & Git Workflow Skill

## Guidelines
1. **Conventional Commits**: Format commit messages as `type(scope): concise description` (e.g. `feat(auth): add JWT refresh token endpoint`). Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`.
2. **ADR Recording**: Save architectural decisions in `docs/adr/000N-title.md` following standard ADR format.
3. **Lessons & Logs**: Record bug solutions and key lessons in `docs/lessons/` and log major project modifications in `docs/logs/`.
