# UI/UX Pro Max Skill

## Core Rules
1. **Design System First**: Define global CSS tokens (colors, spacing, typography, elevation) before building components.
2. **Color Palette Harmony**: Use 60-30-10 color distribution rule (60% background/neutral, 30% secondary/surface, 10% accent).
3. **Responsive Grid**: Ensure mobile-first responsive layout with dynamic container bounds (never hardcode pixel offsets).
4. **Interactive Feedback**: Implement focus-visible rings, button active states, and hover feedback on all interactive elements.
